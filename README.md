# Portfolio

This project is ready to be hosted on GitHub Pages.

## Steps to publish

1. Commit and push the files to GitHub.
2. In your GitHub repository, go to Settings → Pages.
3. Under Source, choose the main branch and the root folder (/).
4. Save and wait a few minutes for the site to publish.

Your site will then be available at:

https://markarmstevem-stack.github.io/PortfolioMark/
